# 申込後のLINE送信案内

申込送信後に「あと1ステップ」のダイアログを表示する。専用コードを含む既存LINEリンクを主ボタンに設定し、LINEを開いた後に送信操作が必要であることを明記する。初参加・リピーター、掲載イベント・自由記入で共通。

Googleへの送信はno-corsのため受理完了とは断定しない。コードは保存・計測せず、画面離脱時にダイアログとリンクから除去する。閉じると既存のコピー方法・申込内容を確認できる。旧フォーム設定では専用コードを生成せず従来の送信文を案内する。

反映対象はUnity_Sの静的サイトのみ。Google Apps ScriptやCloudflareの設定変更は不要。

検証：Nodeの既存20テスト、Chromium・WebKitの申込フロー（4画面幅、掲載・自由記入、ダイアログ、コピー、離脱時コード除去）。実フォーム・LINEへは送信しない。
